CURRENT PROGRESS

目前核心架構

可直接操作網站前台與管理介面，確認導覽、內容結構與未來維護方式。

01 FRONTEND

完整前台架構

主要內容頁與多層導覽皆已建立。

  • 產品分類、品牌、產品詳細頁
  • 下載中心與品牌快速入口
  • 系統方案、客戶案例、最新消息
  • 關於我們、服務據點、聯絡表單
  • 桌機、平板、手機 RWD
02 MANAGEMENT

公司自行維護

預覽管理介面已可操作，正式版規劃改接 MySQL 與帳號權限。

  • 新增／修改產品與規格
  • 管理產品圖片與文件資料
  • 管理下載中心與系統方案
  • 管理消息、案例、公司基本資料
  • JSON 匯出作為預覽期資料備份
03 PORTABILITY

可移植正式主機

GitHub 僅為目前沒有正式主機時的預覽環境。

  • 已規劃正式 MySQL 資料結構
  • 正式主機可使用 PHP / Laravel 類型後端
  • 大型驅動與 PDF 可獨立放檔案空間
  • 預留 SEO、Sitemap、Canonical
  • 舊網址可用 301 Redirect 保留搜尋權重
WHY IN-HOUSE

與目前外包維護方式比較

項目目前外包模式新版規劃
新增產品需整理需求、聯絡廠商、等待修改公司登入後台自行新增與發布
修改規格／圖片小改動也需來回確認直接於後台修改
最新消息依現有維護流程處理公司自行建立、編輯、上下架
下載檔案由網站廠商架構管理檔案空間與網站資料分離，可自行管理
網站搬家受原系統與廠商交付內容影響程式、資料庫、圖片與檔案皆規劃可移植
PRODUCTION PATH

公司決定採用後

01建立正式主機Linux / PHP / MySQL，建立正式檔案空間。
02完整資料搬移搬產品、圖片、規格、下載文件、消息與案例。
03正式後台上線登入權限、檔案上傳、表單寄信與備份。
04網域切換SSL、DNS、SEO、舊網址 301 後正式取代舊站。

核心目標

未來新產品、新驅動、規格、圖片、消息或服務內容有變更，公司可以自行處理，降低每一次小修改都需委託外部網站廠商的溝通與維護成本。
